# ◤ AXIOM_VECTOR_SURGE_3D // Bare-Metal Simulation ◢

¡Bienvenido al Enclave! **AXIOM_VECTOR_SURGE_3D** es un simulador interactivo de evasión multi-raíl en 3D hiperbólico, construido bajo una filosofía estrictamente monolítica. Todo el motor gráfico, la síntesis de audio procedural y la lógica de estado residen en un único archivo de alto rendimiento optimizado para pantallas móviles de **120Hz**.

## 🧬 Características del Núcleo
* **Gráficos Bare-Metal:** Renderizado wireframe de vectores de luz nativo por GPU utilizando `Three.js` sin capas intermedias pesadas.
* **Audio-ID Procedural:** Frecuencias generadas en caliente mediante `Web Audio API` que mutan de ritmo y tono en base al Overclock de velocidad por CPU del jugador.
* **Watermark Cinético (Fuerza G):** Sello de autor responsivo que sufre distorsión y deformación matricial por código (`skewX` y `translate`) según la inercia del carril.
* **Mecánica de Grieta Segura:** Sistema de riesgo/recompensa donde debes deslizar el dedo para cruzar el bloque de datos por la zona abierta antes del colapso.
* **Persistencia Asíncrona:** Arquitectura preparada para inyectar marcas de marcas directamente en el búnker de Supabase Auth.
